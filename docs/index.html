What it does

  • Customers and invoicesKeep your customers in one place and raise invoices with line items, VAT and notes.
  • PDF exportSave or open any invoice as a PDF with your logo and company details.
  • Duplicate an invoiceRepeat work? Copy a past invoice and only change what's different.
  • Local and privateEverything is stored in a database on your computer. No account, no cloud.
  • Updates itselfThe app tells you when a new version is out and installs it for you.
  • Free and open sourceMIT licensed. The code is on GitHub.

Opening it for the first time

The installers aren't signed with an Apple or Microsoft certificate yet, so your computer will warn you the first time.

  • macOS: move it to Applications and open it. When macOS says it can't verify the app, choose Done, then go to System Settings → Privacy & Security and click Open Anyway. You only need to do this once.
  • Windows: on the SmartScreen prompt, choose More info, then Run anyway. If Windows says Smart App Control blocked it, the app can't be installed while Smart App Control is on. Turning it off in Windows Security can't be undone without resetting Windows, so only do that if you're comfortable with it.
  • Linux: make the AppImage executable with chmod +x, then run it. If it fails with an error about libfuse.so.2, install FUSE 2: sudo apt install libfuse2t64 on Ubuntu 24.04 and later, or libfuse2 on 22.04. You need Ubuntu 22.04, Debian 12, Fedora 36 or newer. If the window opens blank, start it with WEBKIT_DISABLE_DMABUF_RENDERER=1.
